# Food Safety Bytes Website

Cloudflare Pages deployment settings:

- Framework preset: Vite
- Build command: npm run build
- Build output directory: dist

## Recommended deployment path

1. Create a GitHub account/repository if you do not already have one.
2. Upload all files in this folder to a new repository.
3. In Cloudflare, go to Workers & Pages > Create application > Pages > Connect to Git.
4. Select the repository.
5. Use:
   - Framework preset: Vite
   - Build command: npm run build
   - Output directory: dist
6. Deploy.
7. After deployment, add your custom domain:
   - foodsafetybytes.com
   - www.foodsafetybytes.com
